# Mesh data model and attribute contract

`shapewright/mesh.py`. Tests: `tests/test_mesh_contract.py` (run against every
registered op).

## Problem (v0.1)

`Mesh(V, F)` had positions and triangles only. Provenance, per-face materials,
colours, authored UVs and region tags had nowhere to live. Every future
capability that needs them (selectors, multi-material parts, texturing,
import, rigging) would have forced each op to be rewritten later, once there
were many more of them. See DESIGN_REVIEW §4 and §7.

## Alternatives considered

| Option | Why not |
|---|---|
| Free-form `dict` of arrays on the mesh | no contract: ops cannot know how to carry an unknown attribute; silent loss |
| Adopt trimesh's `Trimesh` + `visual` as the kernel type | couples every op to one library (the backend-boundary goal); visuals are render-oriented, not semantic |
| Half-edge / polygon mesh (OpenMesh-style) | better for quad editing, but a large rewrite; the output domain is triangles |
| **Typed schema + per-op topology class + explicit correspondence** | chosen |

## The model

```
Mesh
  V (n,3)  F (m,3)                   welded, indexed triangles
  vattr  name -> (n, w)             vertex domain
  fattr  name -> (m,) codes | (m,w) face domain
  cattr  name -> (m, 3, w)          corner domain (one value per face corner)
  labels name -> tuple[str]         dictionary for label attributes
  invalidated: set[str]             attributes an op had to drop
```

**Schema (closed; `mesh.SCHEMA`):**

| name | domain | kind | meaning | glTF |
|---|---|---|---|---|
| `origin` | face | label | provenance: source path of the geometry expression that created the face (`parts.lantern_frame.ops[1].shape`, `file:source/rock.glb#node`) | extras only |
| `material` | face | label | material name; unset = the part's material | one primitive per material |
| `region` | face | label | surface region (`top/bottom/left/right/front/back/bevel/cut`, generator-defined) | — |
| `color` | vertex | float×4 | linear RGBA | `COLOR_0` |
| `uv` | corner | float×2 | authored/imported/locked UVs | `TEXCOORD_0` |

Setting an unknown name raises. **Normals and tangents are derived**: they are
never stored and are always regenerated by the surface stage from geometry and
shading settings, so they can never go stale.

Label attributes are dictionary-encoded per mesh. `concat` remaps codes, so
meshes built independently merge safely.

## The contract: topology classes

Every op must declare one (`@op(..., topology=...)`). The registry refuses ops
without one.

| class | vertex attrs | face attrs | corner attrs | ops |
|---|---|---|---|---|
| `preserve` | preserved | preserved | preserved | scale, rotate, translate, taper, bend, twist, shear, jitter, noise, inflate, smooth |
| `refine` | interpolated (edge midpoints) | inherited by child faces | interpolated (barycentric) | subdivide |
| `rebuild` | interpolated (through Manifold vertex properties) | inherited from the source face (Manifold per-triangle provenance) | **invalidated** | subtract, union, intersect, flat_bottom, mirror, repeat, boolean, combine |
| `resample` | transferred (nearest vertex) | transferred (nearest face) | transferred: each new face maps its corners through the one source face under its centroid, so a face never straddles two UV charts (Phase 11; before, **invalidated**) | decimate (and future remesh) |
| `generate` | defaults | assigned: `origin` = expression path, `region` by normal | absent | generators, `mesh_file` (which carries file UVs/colours) |

Mechanics: topology-changing ops build the new mesh with
`Mesh.remapped(V, F, face_src, vert_src, vert_w, corner_bary)`, an explicit
correspondence. Faces with `face_src = -1` are new (for example trim caps).
The op labels them (`region: cut`, `origin` = the op's path).

Specific rules:
- **Mirror transforms** (negative determinant) flip winding and reverse corner
  order, so corner attributes stay attached to their vertices (tested).
- **Weld (`merged`)** only merges coincident vertices whose vertex attributes
  are equal; a colour seam stays a seam (tested).
- **Split (`subset`)** preserves everything.
- **Merge (`concat`)** unions schemas; missing values get defaults, and a
  missing corner attribute marks that attribute invalidated.
- **Booleans:** Manifold merges coplanar triangles into faces. Two coplanar
  inputs with different labels can come back under one label. *Known
  limitation*, visible in `--mode provenance`.
- **Invalidation is reported, not silent:** `ATTR_INVALIDATED` (a warning if a
  `mesh_file` part lost its authored UVs; info otherwise).

## What this enables now

- `--mode provenance` and `--mode regions` renders: which expression made which
  faces (for example boolean cut faces).
- Per-expression materials: `{type: ..., material: iron}` inside a boolean tool
  colours the cut faces. The exporter writes one glTF primitive per material.
- Imported UVs and vertex colours survive into the surface stage and export.

## What it does not do yet

- There is no user-facing selector syntax over regions (`faces: {region: top}`);
  the data exists and selectors are the next consumer.
- Corner attributes through booleans (possible via Manifold property channels
  with unwelded vertices) are deliberately invalidated for now.
- No skin weights or morph targets. The schema is the place to add them, each
  with a policy per topology class.
